# source-command-st-help

`st-help` 요청은 `st-start`로 위임한다. 먼저
`agent-packages/smartthings-translation-agent/commands/st-start.md`와
`agent-packages/smartthings-translation-agent/commands/README.md`를 읽는다.
그 공통 원본의 6개 기본 명령·별칭·자연어 입력 흐름을 한국어로 짧게 안내한다.
상태/재개는 `references/command-execution.md`를 따른다. 상태 질문만으로 실행하지 않는다.
세부 검수 단계와 실행 절차는 이 파일에 복제하지 않는다.
