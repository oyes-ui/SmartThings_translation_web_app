# SmartThings ChatGPT for Excel Live Layer

OpenAI 공식 ChatGPT for Excel과 Codex 데스크톱 앱에서 열린 SmartThings workbook을 검수·수정하기 위한 지침입니다.

다른 Codex 계정에 이 폴더를 ZIP으로 첨부한 후 아래와 같이 요청합니다.

```text
첨부한 Excel layer 전체를 읽고 SKILL.md와 references/를 이 작업의 지침으로 적용해 주세요.
현재 열려 있는 Microsoft Excel workbook만 대상으로 작업하세요.
수정 전에는 반드시 대상 sheet/range와 before → after preview를 제시하고,
제가 명시적으로 승인하기 전에는 어떤 셀도 수정하지 마세요.
연결 가능한 경우 @Microsoft Excel을 사용하세요.
```

이 폴더는 ChatGPT for Excel의 `+` 메뉴에 업로드하는 설치 파일이 아닙니다. Codex가 이 레이어를 읽고,
같은 컴퓨터에서 열려 있는 Excel workbook에 연결해 적용하는 작업 지침입니다.
