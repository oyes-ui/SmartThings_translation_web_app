argument-hint: <질문 또는 표현>
---

질문에 맞는 기존 경로만 읽는다. 규칙·표현 판단은 `commands/st-rules.md`,
용어집 조회는 `commands/st-glossary.md`, 과거 사례는 `commands/st-rag.md`를 따른다.
답변은 `references/response-patterns.md`에 따라 근거와 판단을 구분한다.
질문 자체를 Excel 수정·용어집 변경·유료 API 실행 승인으로 해석하지 않는다.

업무 후 개선점·반복 문제·승인 결과 분석을 요청하면 `references/improvement-loop.md`를 읽는다.
현재 대화의 대상 기록과 요청 범위를 재사용하며, 분석 요청은 근거·개선안까지 수행한다.
번역·도구 사용·업무 진행의 작은 지적 한 건도 분석 대상이 될 수 있으며 반복 발생을 요구하지 않는다.
반영·검증까지 요청받았거나 이미 승인된 범위가 있으면 그 범위로 이어간다. 별도 명령은 만들지 않는다.
