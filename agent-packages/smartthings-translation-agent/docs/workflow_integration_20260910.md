핵심 파일은 `workbook_batch.py`, `workflow_approval.py`, `glossary_sync.py`다. 기존 번역 래퍼·검수 조정기·독립 Excel 검증 실행기를 재사용한다. 새 사용자 명령·검수 API·데몬·DB·그래프 엔진은 추가하지 않았다.

API 기본값은 초벌 번역·기입·하이라이트다. API 검수와 역번역을 각각 명시적으로 선택해야 한다. 유료 호출 전 durable 상태를 저장하고, 완료 receipt가 있으면 무료 로컬 단계만 재개한다. 결과가 불확실한 중단이나 실패 호출은 자동 재실행하지 않는다. 일부 실패와 정상적인 수정 후보 없음은 승인표에서 구분한다.

승인표는 기존 후보 ID·문안을 원본 manifest와 연결한다. `--workflow-settings`로 승인 반영까지 같은 원문·용어집·활성화·언어 매핑을 전달한다. 사용자 승인 자체를 자동으로 만들지 않는다. 자동 생성 블록 밖의 사용자 메모는 재생성 시 보존한다.

## 운영 경계

실제 유료 번역·언어 품질 평가, Google Sheets 변경, 실제 사용자 Obsidian 폴더 쓰기는 이번 구현 검증에서 실행하지 않았다. 검수는 현재 활성 에이전트가 준비된 prompt를 실행해야 하며 CLI만 실행해 둔다고 모델이 자동 기동되지는 않는다.

다중 언어는 독립 초벌 사본을 생성한다. 모든 결과를 한 Excel로 자동 재조립하는 추가 단계는 없다. Google Sheets 편집은 별도 Drive/Sheets 스킬을 사용한다. DB와 기본 CSV 교체는 분산 트랜잭션이 아니며 CSV 실패는 별도 sync-default로 복구한다. 시트 복제는 차트·이미지·주석 상자 등 미지원 객체를 거부한다. 외부 앱의 초벌 writer 전체 이전과 역사적 일회용 writer 일괄 이전은 포함하지 않았다.
